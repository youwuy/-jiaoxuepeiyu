# Web教辅系统项目分工说明

## 项目技术约定

- 前端：Vue 2.x 或 Vue 3.x，Node 18+，Element UI / Element Plus。
- 后端：Java 8，Spring Boot，MyBatis / MyBatis-Plus，MySQL 5.7.42。
- 部署：部署包需包含 Java 相关运行库，不要求客户服务器额外安装 Java 环境。
- 数据库：MySQL 5.7.42，初始化脚本由后端提供。

## 分支规划

- `main`：项目主分支，仅合并已联调验证的稳定代码。
- `zhan/frontend-test`：占工开发分支，负责前端和测试相关工作。
- `chen/backend`：陈工开发分支，负责后端全部工作。

## 占工：前端与测试负责人

### 前端开发范围

占工负责管理端和学员端全部前端页面、交互、联调和前端自测。

#### 管理端页面

- 登录页。
- 用户管理：教师管理、学员管理、新增、编辑、查看、禁用、重置密码、批量导入、导出。
- 功能管理：一级菜单、二级菜单、功能按钮。
- 角色管理：角色信息、功能权限、数据权限。
- 组织管理：多级组织架构。
- 配置信息管理：学年学期、专业目录、班级、实训室、摄像头 RTSP 配置、固定设备数量配置、成绩等级、综合成绩权重。
- 个人资源库：资源上传、编辑、预览。
- 资源公开申请：申请、审核、驳回。
- 公开资源库：查看、预览、下载。
- 理论试题：新增、编辑、删除、批量导入。
- 理论试卷：手动组卷、自动组卷、批量导入。
- 教学课程：创建课程、教学团队、授课班级、章节维护、课件资源引用、作业配置、学习进度统计、作业批改。
- 实训课：实训课配置、发布、开始实训、组队房间、角色选择、AI 状态标记。
- 监考页面：单实训室最多 4 路 RTSP 画面展示、单学员桌面共享查看、在线状态展示。
- 阅卷页面：实训步骤、成绩、评语、实训录屏查看。
- 综合成绩：成绩列表、线下成绩导入、综合成绩详情。
- 实训档案：学员实训记录、步骤明细、成绩明细、录屏查看。
- 设备/在线状态统计：实时在线人数、IP、在线状态、实训室固定设备数量展示。
- 个人中心：个人信息查看、手机号、身份证号、密码修改。

#### 学员端页面

- 登录页：学号密码登录、手机号密码登录。
- 课程学习：课程列表、课程搜索、自由学习模式、顺序解锁模式、课件学习、学习进度统计。
- 课程作业：理论作业答题、理论作业报告、实训作业、作业提交、截止时间控制。
- 实训中心：实训列表、实训状态、单人实训、多人实训。
- 组队实训：创建房间、加入房间、选择任务、选择角色、未选角色显示 AI 扮演。
- 三维程序启动：通过后端返回或页面组装的命令行参数启动用户本地三维实训程序。
- 实训成绩详情：分步骤成绩、个人得分、用时、操作记录。
- 资源学习：公开资源查看、分类筛选、资源预览。
- 个人中心：个人信息、综合成绩、消息通知、实训档案。
- 消息通知：课程通知、实训通知、资源上新通知、标记已读。

### 测试工作范围

占工负责组织测试用例、功能测试、联调测试和回归测试，开发自测仍由各自开发人员完成。

- 编写测试用例清单。
- 执行前端页面功能测试。
- 执行接口联调测试。
- 执行 RTSP 视频流、桌面共享、录屏上传专项测试。
- 执行主流程回归测试。
- 记录 bug、跟踪修复状态、验证修复结果。
- 协助客户测试、部署验证和上线验收。

## 陈工：后端负责人

陈工负责后端全部内容，包括数据库设计、业务接口、第三方/三维程序对接接口、部署和后端自测。

### 基础系统

- 登录认证、会话管理、登录超时。
- 权限体系：功能权限、角色权限、数据权限。
- 用户管理：教师、学员账号维护、禁用、重置密码、批量导入、导出。
- 组织管理：多级组织架构。
- 配置信息管理：学年学期、专业目录、班级、实训室、摄像头 RTSP 地址、固定设备数量、成绩等级、综合成绩权重。
- 在线状态：30 秒心跳，2 分钟无心跳或退出登录判定离线，记录在线人数、IP、在线状态。

### 教学与资源

- 个人资源库、资源公开申请、公开资源库。
- 理论试题、理论试卷、自动组卷、手动组卷、批量导入。
- 教学课程、章节、课件资源引用、作业配置。
- 课程学习进度统计。
- 理论作业、实训作业提交与批改。

### 实训链路

- 实训课新增、编辑、发布、开始实训。
- 单人实训、多人实训。
- 组队房间：创建房间、加入房间、退出房间、解散房间。
- 角色选择：角色占用、角色释放、未选择角色标记为 AI 扮演。
- AI 补位仅作为界面状态和启动参数标识，不包含 AI 算法、AI 行为逻辑或 UE 内 AI 控制。
- 学员端启动本地三维实训程序所需参数生成。

### 三维程序对接接口

UE 端三维实训程序由甲方/现有团队开发，不属于本项目开发范围。后端仅提供供三维程序调用的接口。

- 获取实训任务信息接口。
- 提交实训成绩接口。
- 提交步骤明细接口。
- 上传或关联实训录屏接口。
- 提交实训状态接口。
- 接口文档由后端编写并维护。

### 视频与桌面共享

- RTSP 摄像头地址、账号、密码后台配置。
- 按海康 RTSP 接入方式适配。
- 单个实训室最多 4 路实时查看。
- 不做监控录像存储，录像由摄像头自带存储能力承担。
- 桌面共享仅接入 1 名学员画面，可采用 WebSocket、定时截图或双方确认的轻量方式。
- 不开发独立桌面采集客户端，不做远程桌面控制。

### 成绩与档案

- 实训成绩记录。
- 实训步骤明细。
- 实训录屏上传与播放数据。
- 综合成绩计算。
- 线下成绩导入。
- 实训档案查询。

### 部署交付

- 数据库初始化脚本。
- 后端配置文件。
- 后端部署包。
- 接口文档。
- 部署说明。
- 后端核心接口自测。

## 双方联调交接点

- 登录认证和权限菜单接口。
- 用户、组织、班级、实训室、摄像头配置接口。
- 课程、资源、题库、试卷、作业接口。
- 实训课、房间、角色、AI 标记接口。
- 本地三维程序启动参数接口。
- 三维程序回传成绩、步骤、录屏接口。
- RTSP 播放地址/流媒体转发接口。
- 桌面共享画面接口。
- 在线人数、IP、在线状态接口。
- 综合成绩、实训档案、消息通知接口。

## 当前确认边界

- 监控只做单实训室最多 4 路 RTSP 实时查看，不做监控录像存储。
- 桌面共享只接入单个学员画面，不开发独立客户端。
- UE 三维实训程序由甲方/现有团队开发，本项目只负责命令行启动参数和数据回传接口。
- AI 补位只做未选角色标记为 AI 扮演，不做 AI 算法或 UE 内 AI 控制。
- 设备统计只统计实时在线人数、IP、在线状态；实训室设备数量为固定配置，后台可维护，不接硬件采集。
- 在线状态按 30 秒心跳上报，超过 2 分钟无心跳或退出登录判定离线。
